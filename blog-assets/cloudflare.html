Cloudflare Workers

Stateless Edge Routing

Incoming webhooks from Stripe or GitHub are received instantly at the closest global edge node. Workers perform fast validation, routing, and handshake negotiations in under 5ms.

  • ✦ Zero cold-starts at the edge
  • ✦ Global HTTP request handling
📦

Durable Objects

Stateful Coordination

A single, globally unique coordinator instance handles each channel. It holds the active Server-Sent Events (SSE) connection open, buffers webhooks when the browser goes offline, and manages backpressure.

  • ✦ In-memory active SSE stream management
  • ✦ Auto-hibernate when idle ($0/mo cost)

The $0/mo Scale: Because Durable Objects hibernate when there are no active HTTP connections or SSE streams, we store no persistent server processes. The entire system scales to millions of users on Cloudflare's free tier.
